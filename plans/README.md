# SkyChain Plans

This directory contains the build plan and specifications for SkyChain — a modular, lightweight blockchain for IoT data built using Proof-of-Authority (PoA) consensus.

Each phase builds incrementally and can be developed independently using agentic tooling.

## Files
- `MVP.md` — Core blockchain, single validator, JSON storage
- `GOAL1.md` — Device registry and key management foundation
- `GOAL2.md` — Device signatures and gateway validation flow
- `GOAL3.md` — Merkle tree computation for block contents
- `GOAL4.md` — Inclusion proof API for recorded events
- `GOAL5.md` — Startup validation and audit routines
- `GOAL6.md` — Multi-validator block proposal rotation
- `GOAL7.md` — Quorum signing and consensus finalization
- `GOAL8.md` — Validator governance transactions
- `GOAL9.md` — Metrics collection and exposure
- `GOAL10.md` — Web dashboard for chain observability
- `SPEC.md` — Full system specification for implementers
